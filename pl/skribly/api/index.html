Czym jest

Skribly API będzie jednym adresem REST API Skribly, więc agent albo skrypt ma jedno miejsce, od którego zaczyna.

Na razie to przekierowania i jeden plik statyczny, a nie działająca usługa.

Co robi dziś

  • Trasy, które kierują każdą ścieżkę do aplikacji, która na nią odpowiada.
  • Manifest API, pisany z rejestru produktów Skribly Core.

Na czym jest zbudowany

nginx i małe skrypty Node.

Na jakim jest etapie

Trwają prace: nie jest jeszcze publiczny.
